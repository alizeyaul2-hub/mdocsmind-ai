In a Gated Recurrent Unit (GRU), the update gate (z_t) simultaneously controls both how much of the previous activation to keep and how much new candidate state to incorporate.

Unlike an LSTM, which has two independent gates—a separate forget gate and input gate—the GRU couples them into a single linear interpolation:

h_t = (1 - z_t) * h_{t-1} + z_t * h~_t

Developer SDK

Integrate RAG With 3 Lines of Code

Embed document intelligence into your own backend services with our Python SDK or REST API. 

# Python SDK
import documind

client = documind.Client(api_key="your_api_key")

# 1. Ingest PDF
doc = client.documents.upload("./pdfs/GRU.pdf")

# 2. Query with MMR RAG
response = client.rag.query(
    document_id=doc.id,
    question="How does the update gate work?",
    retrieval_strategy="mmr",
    k=4
)

print(response.answer)
print("Cited Pages:", response.sources)
